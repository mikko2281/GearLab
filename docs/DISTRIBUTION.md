# Распространение 6.6.0

Переносимая Windows-сборка включает EXE, Python/OCCT, WebView2, Three.js, документацию, лицензии и самостоятельные CAD-примеры. Установка Python и Blender пользователю не нужна. EXE не подписан цифровой подписью. Архив следует распаковать целиком; один EXE без runtime не является полным комплектом.

Текущий модуль промышленного манипулятора создаёт параметрические корпуса и опоры независимо от игрового образца. Предыдущий ошибочный импорт удалён из актуальных примеров. Полная машина не допущена к изготовлению: выбранные редукторы, рабочая характеристика моторов, осевая фиксация и прочность требуют подтверждения; см. industrial-design-66/README.md.

Архивы опубликованных версий не заменяются. Текущая версия, SourceCommit и SHA256 EXE записаны в build-info.json. Проверка переносимого комплекта выполняется tools/verify_package.py.
