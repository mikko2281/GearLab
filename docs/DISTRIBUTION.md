# Переносимый комплект Windows

Распакуйте весь GearLab_5.3_Windows.zip в отдельную папку и запустите GearLab.exe. Не переносите только EXE: нужны соседние DLL, runtime, kernel, web, examples и уведомления библиотек. Требуются Windows 10/11 x64 и .NET Framework 4.8. Three.js использует установленный WebView2 Runtime; резервный WPF-просмотр доступен без него.

Редукторы открываются кнопкой «Редукторы», затем выбирается тип. Отдельного раздела и отдельного запуска волнового редуктора в комплекте нет. Параметр командной строки --wave сохранён для совместимости и открывает общий раздел с выбранным типом «Волновой».

Сборка не подписана сертификатом издателя. Предупреждения и ограничения Windows могут сохраняться; бесплатность и размещение на GitHub не устраняют их. Программа не меняет настройки защиты Windows. build-info.json содержит состояние подписи и SHA256, SHA256SUMS.txt — контрольные суммы файлов. tools/Check-Windows.ps1 выполняет диагностику чтением.

Собственный код распространяется по FREEWARE.txt без общей открытой лицензии. В licenses и web/vendor находятся условия и уведомления сторонних библиотек. Исходный архив подготовлен отдельно; загрузка на GitHub автоматически не выполняется.
