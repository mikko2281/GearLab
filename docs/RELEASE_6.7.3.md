# GearLab 6.7.3 — локальная сборка для проверки

«＋ Следующее звено» продолжает локальное направление родителя на 140 мм. В процедурной цепи начало совпадает с концом родителя. Для старого балочного примера без генератора сохранён шаг 100 мм. При направлении преимущественно по Y выбирается ось X, иначе Y.

«＋ Параллельная ветвь» создаёт независимую корневую цепь рядом с выбранным звеном, в его текущем мировом направлении. Размеры и механические параметры копируются, настройки генератора независимы, прежний CAD-кэш не копируется. Для новой цепи используется общий процедурный профиль: фиксированные профили шестиосевых примеров привязаны к исходным номерам суставов. Это отдельная цепь, не разветвляющий механический фланец.

Новые регрессии вызывают методы формы AddJoint/AddParallelBranch, проверяют мировые координаты, направления, CAD-корпуса, фланцы, undo/redo. Для короткого осевого звена с потомком поиск креплений крышки дополнен закруглёнными краями панели и рёбрами, обрезанными по защищённым объёмам приводов; полная длина посадки термовставки сохраняется.

Исправлена отмена перетаскивания шарнира: восстановление читает компактный кадр позы, введённый в 6.7.2, не пытаясь открыть его как полный проект. Общий запуск `test.ps1` использует актуальный `wave56-fast` вместо исторического `reducer56`, ожидающего прежнюю модель передачи. Действующий `author-view` сохранён в основном наборе. Исторические файлы не удалены.

Micro-тест считает шесть подшипниковых сборок по исходному подшипнику и проверяет внутренние/наружные кольца и шарики, учитывая введённую ранее детализацию вместо шести условных тел.

В connected-тесте выбор передачи выполняется после готовности вновь открытой вкладки: прежний немедленный выбор мог быть перезаписан её первоначальной инициализацией.

Ветка `fix/add-link-direction`; только локальный коммит и переносимый комплект. Слияние в main, push, тег и публикация релиза выполняются после подтверждения пользователя.

Конструкция остаётся предварительной. Номинальная высота 1 м, целевой груз 300 г, P1S/PETG/NEMA17; рабочая характеристика двигателя не предоставлена. Геометрические тесты не подтверждают готовность к изготовлению.
