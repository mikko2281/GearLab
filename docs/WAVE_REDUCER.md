# Волновой редуктор

Откройте **Редукторы → Тип редуктора → Волновой**. Все типы передач используют одну вкладку раздела. Кнопка **CAD Studio → Твёрдое тело → Волновой редуктор** открывает этот же раздел для вставки в текущий CAD-проект.
Есть пресеты **50:1, 80:1, 100:1** и собственные размеры. Нажмите «Построить» после изменения полей.

Сборка содержит отдельные точные CAD-тела: жёсткий внутренний венец, тонкостенную чашку с наружными зубьями, эллиптический генератор и подшипниковое кольцо. Последнее показывает монтажный объём подшипника; шарики, сепаратор и реальные дорожки качения не моделируются.

Число зубьев чашки `Zf = 2 × |i|`, венца `Zc = Zf + 2`. При закреплённом венце:

`n_out = −n_in / |i|`

`T_out = T_in × |i| × η`

`T_in_required = T_load / (|i| × η)`

`P_in = T_in × n_in × π / 30`

Для 50:1, 60 об/мин, 0,35 Н·м и КПД 0,70 получаем −1,2 об/мин и 12,25 Н·м. Это переданный момент при заданном КПД, **не допустимая нагрузка редуктора**. Вводите момент мотора именно на выбранных оборотах. КПД — входное допущение, не результат расчёта трения.

«▶ / ❚❚» показывает вращение генератора, медленный обратный поворот чашки и заданную эллиптическую деформацию её верхней части. Дно остаётся круглым. Скорость просмотра изменяет только анимацию. «Сечение» и «Разнести детали» помогают рассмотреть внутренности. STEP текущей фазы строится заново как B-rep; разнесение служит только для просмотра. «В CAD Studio» открывает отдельный редактируемый проект. «Вставить в модель» добавляет четыре тела одной параметрической операцией в текущий документ. В истории можно изменить модуль, глубину, стенки, отверстия, зазор и фазу; отдельные тела можно дорабатывать обычными CAD-операциями.

Для этой геометрической концепции используются эвольвентные зубья с заданной деформацией. Профиль не воспроизводит коммерческий S-tooth. Сопряжённость и интерференция зубьев во всём цикле, контакт, упругость, усталость чашки, ресурс, люфт, сборочные зазоры, крепление венца и подшипниковый узел не подтверждены. Увеличение зазора генератора не заменяет разработку зубчатого зацепления. Перед изготовлением необходимы отдельный расчёт профиля и контактно-прочностная проверка. Подставлять вычисленный T_out в качестве паспортного предельного момента нельзя.

В конструкторе робота этот выпуск позволяет использовать CAD-геометрию для компоновки и задать передаточное число/КПД шарнира вручную. Автоматическая установка волнового узла и расчёт его прочности в корпусе робота не реализованы.
