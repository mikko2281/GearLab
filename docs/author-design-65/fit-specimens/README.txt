ПРОВЕРОЧНЫЕ ОБРАЗЦЫ. ЭТО НЕ ДЕТАЛИ ГОТОВОГО МАНИПУЛЯТОРА.
STL и STEP — мм, Z=0; 12 образцов посадок и один образец отверстий. Приняты Bambu Lab P1S / PETG; стол 256³ мм; сопло 0,4 мм предполагается, марка PETG не уточнена.
Выберите один тип подшипника и несколько зазоров для пробы. Суффикс 0p20 означает увеличение ДИАМЕТРА на 0,20 мм (по 0,10 мм на сторону).
6204: 20×47×14 мм; 6001: 12×28×8 мм. Это кандидаты только для проверки печати, выбор опор робота не выполнен.
Печатайте при 100% масштабе, отверстиями вверх, тем же материалом и режимом, который планируете для корпуса.
Измерьте отверстие после остывания, отметьте номер удачного образца. Не забивайте подшипник молотком; не передавайте усилие через шарики.
В manifest.json находятся размеры, CAD/STL-проверки и SHA256. Серия определяется размером блока. Число вырезов у края равно зазору × 10: 0 вырезов = 0,00 мм; 2 = 0,20 мм; 5 = 0,50 мм. На пластинке M3/M5 вырезанный угол — начало координат; отверстия слева направо увеличиваются на 0 / 0,2 / 0,4 / 0,6 мм.
