# 6.11.0 — свои редукторы в роботе: «＋ В робота», значки редукторов на модели и их настройка

Дата: 16 ноября 2026. Автор: Claude (Cowork). База: 6.10.0 (рабочее дерево поверх `79920016`, тоже не закоммичено). Итоговый коммит: **ещё не создан**. Статус: **проверено локально** (Wine + Chromium), на Windows не проверено. `ReadyForManufacture=false`.

## Запрос пользователя

1. Редуктор, который человек сделал в редакторе, можно отправить в робота кнопкой «Добавить в робота»; робот собирается из этих редукторов.
2. Редукторы в роботе можно менять: во вкладке «Робототехника» кнопка «Редукторы», на роботе видно, где какой редуктор; щёлкнул по значку — можно настроить.

## Как пользоваться (коротко)

- **Раздел «Редукторы»** → справа сверху синяя кнопка **«＋ Добавить в робота ▾»**. **Раздел «Ступени»** → кнопка **«＋ В робота ▾»** в строке команд (нужна последовательная цепь с одним выходом).
  - Если робота нет (или вкладка робота не открыта) — пункт «Новый робот с этим редуктором»: создаётся новый робот, первое звено — поворотное основание (ось Z) с этим редуктором.
  - Если робот уже есть — «Следующим звеном робота» (звено добавляется в конец руки, продолжает её направление), «Вместо редуктора звена ▸ …» (замена в выбранном звене) или «Новый робот…».
  - «Только сохранить в «Мои редукторы»» — запомнить без робота.
- **Вкладка «Робототехника»** → кнопка **«⚙ Редукторы»** в верхней строке. На модели у каждого подвижного сустава появляется значок ⚙ с номером, именем звена, типом и i. Цвет: зелёный — хватает момента; жёлтый — запас меньше 20 %; красный — не хватает момента мотора/предела редуктора; пунктир — у сустава только число i без модели редуктора.
- Щелчок по значку (или строке списка справа) выбирает сустав и открывает карточку: тип, i, КПД, габарит, предел редуктора («не определено», если метода нет), нужно/доступно. Кнопки: **«Настроить редуктор…»** (открывает тот же редактор, где он был сделан: «Редукторы» или «Ступени»; изменения возвращаются кнопкой «Использовать … в роботе»), **«Заменить на ▾»** (из «Моих редукторов», новый в редакторе, цепь ступеней), «Сохранить в «Мои редукторы»», «Убрать модель, оставить i».
- Каждое добавление/замена — один шаг «Отмена».

## Совместимость и данные

- `web/scene.js` и `web/index.html` обновлены и в `01_Готовая_программа\web` (там их читает `GearLab_6.11.0.exe`). Изменения только добавляют слой значков; старые `GearLab.exe` его не включают и работают как раньше.
- Формат проекта робота **не менялся**: редуктор хранится в существующих полях сустава `ReducerSettings` / `TrainSettings` + `TrainOutput`. Старые роботы открываются как раньше; у суставов без модели значок пунктирный.
- Новый файл `my-reducers.json` в папке настроек — необязательный.
- Расчёты моментов и прочности не менялись.

## Ограничения и продолжение

- Цепь ступеней ставится в сустав только последовательная, с одним выходом и длиной ≤ 180 мм (ограничение существующего `RobotTrainIntegration.Apply`).
- Длина нового звена подбирается по габариту редуктора грубо (≥ 1,7 × Ø); положение звеньев можно поправить на шаге «1 · Звенья».
- Если процедурный корпус не помещается («Недостаточно места между фланцами») — это сообщение корпуса, редуктор при этом стоит.
- Точки входа для доработки: значки — `SendReducerPins` / `web/scene.js setReducerPins`; карточка — `BuildReducerInspector`; постановка — `PlaceReducer`.
