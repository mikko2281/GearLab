# База и сохранение исходных изменений

До работы над составным корпусом базой был `b23c2d6` (исправления 6.7.3): направление добавления следующего звена, независимая ветвь, сопряжения корпусов, история позы. Подробности: [исходная запись](../RELEASE_6.7.3.md).

Перед новыми функциями существовавшие локальные изменения пользователя/интерфейса сохранены отдельным коммитом `163746592b766ac6327f836005153fb2dd150df6`. Это сохранение уже имевшегося состояния, а не заявление, что всё в нём заново написал Codex.

В нём 15 файлов: AppSettings, EditorFields, EditorTabs, GearCalculator, I18n, RobotDesignerForm, RobotWebViewport, RobotWorkspaceUX, SettingsForm, UiAppearance, UiTextCatalog, WorkspaceShell, tools/ui64_catalog.txt, web/index.html, web/scene.js. Они касались оформления, настроек, языка, рабочего пространства и отображения робота.

[Точный patch](patches/1637465-checkpoint.patch), [список файлов](files/checkpoint.txt). Для просмотра: `git show 1637465`; для сравнения дальнейшей работы без этого checkpoint: `git diff 1637465..715f4c5`.

В этой исходной линии отсутствовал `WpfSceneAnimation.cs`. В 6.9.1 анимация восстановлена отдельно из проверенной папки `GearLab-review-claude`. Это объясняет, почему сохранение изменений интерфейса само по себе не вернуло анимацию в 6.9.0.
