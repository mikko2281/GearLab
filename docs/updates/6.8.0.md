# 6.8.0 — составной редуктор в общем корпусе

База: `1637465`. Итог: `30e4a2c016a8a22771eeb83b812ce9a6f578d093`. Ветка на момент реализации: `feature/compound-reducer`; локальный тег `v6.8.0-compound-preview`. Это локальный preview данной линии, не идентификатор другой опубликованной ветки.

## Проблема и результат

Раньше каждая ступень добавляла собственный корпус, основание и условную межступенчатую муфту. Общий корпус стал режимом существующего графа: 2–4 последовательные соосные ступени, одна моторная плита, модули с неподвижными кольцами, перегородки, общий либо D-/шлицевой вал, выходная крышка, опоры, шпильки и гайки.

## Где и как реализовано

| Файл/функция | Изменение и принцип |
| --- | --- |
| `src/CompoundReducer.cs`: модели настроек, `Enabled`, `Validate`, `Ordered`, `Example`, `Build` | Проверка графа и параметров; выбор рабочих деталей из исходного CAD; общая осевая раскладка и размер корпуса; построение своих корпусных модулей и соединений |
| `src/TransmissionTrain.cs`: `TransmissionTrain`, `TrainStage`, `TrainSolver.Solve`, `TrainMotion.At` | Необязательное `SharedHousing`; ограничение допустимого входного момента следующей ступени; прежний расчёт графа остаётся основой; в общем режиме обход отдельных корпусов |
| `src/CadBuilder.cs`: `Build(Result,bool)` | Возможность не разворачивать подробную внутреннюю геометрию подшипников при сборке общего узла |
| `src/CompoundDesigner.cs`, `src/CompoundConverters.cs`, `src/TrainDesignerForm.cs` | Вкладка корпуса, параметры, русские значения выбора, схематический разрез, пример и вывод итогов |
| `src/CompoundExport.cs`: `PrintZip`, `Explode` | Печатный ZIP с BOM/исходным проектом/статусом; разнесение групп модулей |
| `src/RobotTrainIntegration.cs` | Габариты общего узла используются при выборе привода шарнира; слишком длинная цепь отклоняется |
| `src/CompoundTests.cs`, `src/CompoundUiTests.cs`, `tools/test_compound_native.py`, `tools/test_compound_stl.py` | Расчёт, ограничения, UI, параметрические тела, STEP, фазовые положения и печатные сетки |

Обратная совместимость: `SharedHousing=null`/`Enabled=false` оставляет старую сборку. Диаметры соседних валов должны совпадать; ветвления и неподходящие типы отклоняются. Базовый пример: планетарная 4:1 → циклоидальная 20:1, подписанное i=−80, КПД при заданных значениях 0,49.

## Важная последующая поправка

Изначально ПТК в общем корпусе отклонялась, а `RingOutput` проверялся для всех типов. По сообщению пользователя оба ограничения исправлены в [6.9.1](6.9.1.md). Не возвращать эту старую проверку при переносе кода.
