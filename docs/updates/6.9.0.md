# 6.9.0 — материалы, нагрузки и перегрузка

База: `30e4a2c`. Итог: `511a3d06fb0ce155b4a610746d3a50294853426d`. Ветка: `feature/material-loads`; локальный тег `v6.9.0-material-loads-preview`.

## Проблема и результат

Общая геометрия не учитывала назначение разных материалов, реальные расстояния опор выходного вала и частные ограничения нагрузки. Добавлены материалы по ролям/деталям, масса по плотности, консольная нагрузка на выходной вал, отчёты, частные оценки предельного момента и геометрический модуль предохранительной муфты. Показ перегрузки условный.

| Файл | Где и как изменено |
| --- | --- |
| `src/MaterialLibrary.cs`, `src/MaterialConverters.cs` | Встроенные/пользовательские материалы, проверки, назначение и плотность; неизвестные прочностные свойства не заменяются выдуманными значениями |
| `src/CompoundReducer.cs` | Необязательные модели `TrainMaterialSettings`, `TrainMaterial`, `TrainOutputLoad`, `TrainOverloadSettings` |
| `src/TrainStrength.cs`: `Validate`, `Beam`, `Calculate`, `Report` | Конечность входных данных, балка на двух опорах с консолью, напряжения/прогиб при наличии свойств; частные оценки разрушения и перечень неизвестных методов |
| `src/TrainClutch.cs` | Собственный геометрический модуль муфты, ведомый вал и опоры; расчёт момента/прижима по заданной паре трения |
| `src/MaterialLoadsDesigner.cs` | Вкладки материалов, нагрузок и перегрузки; библиотека, таблицы, эпюра и отчёты |
| `src/OverloadAnimation.cs`, `src/TransmissionTrain.cs`: `TrainMotion` | Условная остановка выходной части при перегрузке с продолжающимся входом; это не расчёт реальной скорости проскальзывания |
| `src/TrainJson.cs` | Каноническое сравнение JSON для undo/redo: порядок отражённых/локализованных свойств не создаёт ложное изменение |
| `src/TransmissionExport.cs`, `src/CompoundExport.cs`, `kernel/transmission_assembly.py` | Материал/плотность/источник в STEP и BOM, отчёты в ZIP |
| `src/RobotTrainIntegration.cs` | Применение предела редуктора к приводу и предупреждение по моменту |
| `src/OverloadTests.cs`, `src/OverloadUiTests.cs`, `tools/test_materials_native.py` | Расчётные примеры, UI/история/недопустимые числа, STEP-материалы и CAD |

Свойства материалов и формулы: [MATERIALS_AND_LOADS.md](../MATERIALS_AND_LOADS.md). `Materials=null` сохраняет прежний расчёт плотности. Неприменимые методы остаются «не определено»; КПД не выводится из одного коэффициента трения материала.

Проверки: 29 расчётных утверждений материалов/нагрузок, UI, RU/EN, история, сечения, старые цепочки и робот, native STEP с материалами и печатные сетки. [Подробный отчёт 6.9.0](../verification/6.9.0/README.md). Анимация показа Клода в этой версии ещё отсутствовала и восстановлена в 6.9.1.

Ограничения: модель сплошных объёмов без заполнения слайсера; линейная балка без концентраций/ползучести; муфта — предварительная компоновка; ресурс, тепловой режим и рабочая характеристика двигателя не подтверждены.
