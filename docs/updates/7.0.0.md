Дата: 16 ноября 2026. Автор: Claude (Cowork). База: 6.11.0 (рабочее дерево поверх `79920016`; 6.10.0, 6.11.0 и 7.0.0 ещё не закоммичены). Итоговый коммит и тег `v7.0.0` должен сделать Codex по [заданию](../../ЗАДАНИЕ_CODEX_РЕЛИЗ_7.0.0.md). Статус: **проверено локально** (Wine + Chromium), на Windows не проверено. `ReadyForManufacture=false`.

Почему 7.0.0, а не 6.12.0: так решил пользователь — крупный выпуск, собирающий 6.10–6.11 и режим просмотра. Форматы файлов **не ломаются**.

4. Передать Codex: обновить GitHub, выпустить релиз и описать всё новое.

## Как пользоваться

Вкладка «Робототехника» → кнопка **«◎ Просмотр»** в верхней строке (или кнопка «Просмотр» на панели 3D-сцены). Наведите курсор на звено: за ~0,4 с его детали плавно расходятся — внешние (корпус, крышки) дальше, внутренние (диски, подшипники, валы) ближе, детали на одной оси разводятся вдоль оси шарнира. Остальные звенья становятся полупрозрачными. Рядом с курсором — подпись «2 · Плечо · 7 дет.», а над разнесённой деталью — её название. Уведите курсор — через 0,3 с звено собирается. Щелчок по разнесённой детали выбирает её как обычно. Повторное нажатие кнопки выключает режим.

Это только показ: проект, позы и геометрия не меняются, отмена не нужна.

## Ограничения и продолжение

- Разнесение — геометрическое (по центрам деталей), а не по сборочной последовательности. Для очень длинных звеньев сдвиг большой — можно уменьшить коэффициент `spread` в `inspectApply`.
- В запасном WPF-виде (без WebView2) режима нет.
- Точки входа: показ — `web/scene.js` (`inspectApply`), данные — `RobotInspect700.cs` (`InspectPayload`), оптимизация расчёта — `RobotSolver.Solve` / `RobotBuild.CachedCentre`.
