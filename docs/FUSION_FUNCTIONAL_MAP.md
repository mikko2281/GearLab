# Сопоставление с Autodesk Fusion

Обзор выполнен 29.10.2026 по документации Autodesk. Fusion объединяет CAD, сборки, листовой металл, поверхности, T-spline, электронику, генеративное проектирование, рендер, анимацию, FEA, CAM и чертежи. Набор зависит от продукта и расширений. Добавление одинаковых названий кнопок не обеспечивает эти возможности: ниже разделены реализованные операции и отсутствующие системы.

| Область | GearLab 4.0 |
|---|---|
| Эскизы | Плоскости и плоские грани, 8 инструментов, размеры/формулы и 13 типов связей. Численный решатель, без всех специальных связей Fusion и 3D-эскиза |
| Твёрдые тела | B-rep Open CASCADE; примитивы, выдавливание, вращение, лофт, протяжка; join/cut/intersect |
| Изменение | Отверстие, скругление, фаска, оболочка, уклон, press/pull плоской и полной цилиндрической грани; разделение, перемещение, поворот, копии, зеркало, массивы, масштаб |
| История | Редактирование, подавление, откат просмотра, формулы, undo/redo. Ограниченное именование топологии |
| Импорт/экспорт | STEP → точные тела → изменение → STEP; STL; собственный проект с историей. Нет чтения F3D/SLDPRT-истории |
| Сборки/робот | Свободная компоновка механизмов, валы/зубчатые связи, дерево шарниров и корпуса, предварительная статика. Нет универсального решателя сопряжений, контактной динамики и полной проверки столкновений |
| Полигональная сетка | Отдельный редактор, вершины, выдавливание/подразделение, STL/OBJ. Не T-spline и не полноценное восстановление CAD |
| Поверхности, листовой металл, Form | Отдельные рабочие среды не реализованы |
| Прочность и оптимизация | Нет FEA, усталостного расчёта и топологической оптимизации. Масса и предварительная статика не являются их заменой |
| Производство | Нет CAM/траекторий/G-code, ассоциативных производственных чертежей, PCB/электроники |
| Изображения и движение | Технический 3D-просмотр, сечение, кинематика, разнесение, снимки; без фотометрического рендера и полного видеоредактора |
| Дополнительные генераторы | 32 пресета зубчатых деталей и концептуальный волновой редуктор 50/80/100:1 |
