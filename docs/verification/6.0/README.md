# Проверка GearLab 6.0 Preview 2

Итоговый локальный EXE и SHA-256 исходников: `build-verification.json`.

- `transmissions60-results.json`: 594 проверки формул, границ, всех 13 предпросмотров, движения, сохранения и STL. 0 запусков CAD-ядра для предпросмотров.
- `train60-results.json`: 74 проверки графа, долей мощности, 40:1, направлений, циклов, сериализации и движения.
- `robot-transmission60-results.json`: 62 проверки установки новых передач, массы, линейных единиц, магнитного ограничения и сохранения робота/цепи.
- `ui60-results.json`: все 13 семейств в одной MainForm, реальная 3D-сцена, переиспользование геометрии, отсутствие отдельной вкладки для типа, открытие редактора ступеней в рабочем пространстве. ReadyMilliseconds означает ожидание готовности сцены после назначения результата; это не полное время операции от нажатия кнопки.
- `native-results.json`: по каждому новому типу действительный экспорт и повторное чтение STEP в OCCT; все тела валидные и с положительным объёмом. Отдельные STL проверены по CRC, объёму и парности рёбер. STEP содержит 29/29/64/40/29/29/102/9 тел для типов 5–12.
- `train-native-results.json`: общая цепь экспортирована и повторно прочитана — 61 валидное тело.
- `audit60-results.json`: независимые кубы с известными общими объёмами 500/0/0 мм³, включая касание.
- `final-*`: прежние десять C# наборов тестов; все завершились с кодом 0. `final-native`: сохранённые роботы, нативные операции, движение, сечения/эскизы, изменение настоящего STEP, волновой узел и 22 проверки контроллера прошли.

`native-results-ruled-before-rv-update.json` — исторический замер до перехода на гладкие loft и до добавления RV-опор. `ui60-first-attempt-*` — сохранённые диагностики исправленных ошибок, а не результаты итогового выпуска.

STEP-проверки новых профилей подтверждают B-rep валидность, не сопряжение зубьев. Крупные временные STEP/STL и снимки сериализованных сборок не включаются в переносной/исходный архив: их воспроизводят тесты. Эти файлы могут присутствовать только в локальной рабочей папке.

Хостовые GUI-проверки выполнены локально на итоговом Windows-preview2-final-verified/GearLab.exe. Пакет GitHub Actions собирается отдельно из того же кода и повторяет headless/native проверки; он не выдаётся за тот же бинарный файл или повтор GUI-проверок.
