# Проверка и оптимизация GearLab 6.7.2

## Подтверждённые причины

| Проблема | Исправление | Проверка |
|---|---|---|
| Каждое нажатие сохраняло полный робот со STEP/preview | Компактные pose-записи; отдельные структурные snapshots | stability672: ноль сериализаций проекта на 24 движения и undo/redo |
| Повторная загрузка WebGL при WPF Loaded | Геометрия отправляется один раз на новый RobotBuild | lifecycle672: реальные счётчики clear/part uploads |
| Настройки пересоздавали робота | Применение к существующим сценам | lifecycle672 и web-preferences672 |
| Idle-autosave писал неизменённый документ | Checkpoint по revision, сравнение только после изменения | lifecycle672: число сериализаций/записей и recovery после undo |
| Качество/привязка не доходили до WebView | DPR/drawing buffer и translationSnap | actual WebView и shipped-scene Node test |
| Привязка повторно округляла local после world | Одно округление показанного перемещения | stability672: повёрнутое звено и совпадение конечной мировой точки |
| STEP блокировал UI; ZIP допускал повтор/закрытие | Background snapshot, общий busy, atomic write/finally | UI heartbeat, duplicate/close guards, ошибка реального writer, retry |
| Cancel мог автоматически запустить pending заново | Cancellation epoch, очистка очереди и debounce | procedural-cancel672 на работающем native kernel |
| Расчёт пальца/точки нагрузки расходился с CAD | Трансформация пальца и фактический flange/TCP | stability672-core с одной несимметричной массой |

## Измерения

В этой сессии на одной машине исходная 6.7.1: медиана 201,6 мс для восьми переключений захвата, диапазон 188,8–265,9 мс. Результаты исправленной версии находятся в `stability672-performance-results.json`; также сохранены исходные измерения. Сравнение относится к этим действиям и машине, не является универсальным FPS-бенчмарком.

История 24 переключений занимает около 9 КБ; в hot path не сериализуется полный CAD-проект. Качество отображения меняет только разрешение рендера, а не геометрию экспортируемых деталей.

## Границы

Сохранены прежние CAD-кеши и геометрия. Проверки интерфейса выполнялись локально; сервер независимо повторяет headless/native/regression проверки и проверяет переносной архив. Recovery после изменения всё ещё выполняет одну полную сериализацию/запись; в idle этого нет. История ограничена отдельно для undo и redo. Перед публикацией результатов см. фактические *results.* — они являются источником чисел.

Инженерный статус: ReadyForManufacture=false. Это проверка программы; прочность, весь диапазон столкновений, рабочий момент NEMA17, дистанционная передача, привод захвата, посадки и секционирование для P1S требуют отдельного завершения.
