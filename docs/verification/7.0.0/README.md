## Ручная проверка

Проверка выполнена в окне `Windows-7.0.0/GearLab.exe`, снимки — [manual](manual/).

- «Редукторы» → «＋ Добавить в робота» → новый робот: появился первый сустав и его редуктор. Повторное добавление создало второе звено с родителем — первым звеном. Снимки 01 и 04.
- «⚙ Редукторы»: значки на суставах и карточка по щелчку; тип, число i и «Предел редуктора: не определено» видны. Снимок 03.
- «◎ Просмотр»: звено под курсором разносится (277 деталей), при уходе курсора собирается. Снимки 02–03.
- На роботе с настоящим сгенерированным процедурным корпусом звено разносится на 312 деталей; остальные звенья полупрозрачны; после ухода курсора корпус восстанавливается. Снимки 05–07.
- «Ступени» → «Материалы»: PETG и сталь меняют цвет и вид модели; 3D переносится во вкладку. Снимок 08.
- «Нагрузки»: радиальная сила 25 Н на плече 30 мм, стрелки силы/момента, опоры и эпюра; недостающие пределы показываются «не определено». Снимок 09.
- «Перегрузка»: ровно 120% предела, красная тепловая окраска внутренних деталей и предупреждение; корпус скрыт кнопкой «Механизм», чтобы видеть окраску. Снимок 10. Это схематическая оценка, не испытание прочности.

При перемещении 3D между вкладками для удобного масштаба использованы F и колесо мыши. Новых ошибок приложения при ручной проверке не обнаружено. Производительность слабых видеокарт отдельно не проверялась.

## Происхождение и границы выпуска

Перед подготовкой создана резервная копия исходного рабочего дерева и `refs/backup/pre-7.0.0` (`d5dce755f6c946203114e5724b9183e4e85fa77b`). Исходная папка `02_Исходный_код` не очищалась и не переключалась.

GitHub main `da216ea9324bb92108a5125a23bbbe9495e5df90` содержит другую опубликованную линию 6.8.0. По исходному заданию и повторному указанию пользователя выпуск основан на переданном снимке 7.0.0. Для сохранения истории main выполнен merge стратегией ours; параллельные изменения корпусов, истории и оформления из той линии не переносились. PR в main должен сливаться обычным merge без force-push. Теги и архивы старых выпусков не меняются.

Конструкция предварительная: `ReadyForManufacture=false`. Не проверены реальная прочность, ресурс, изготовление, рабочая характеристика момента NEMA17 и непрерывная безопасность на всём диапазоне.
