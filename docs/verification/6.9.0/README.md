# Проверка GearLab 6.9.0

Все перечисленные проверки завершились успешно. Сборка предварительная, публикация не выполнялась. Идентификатор EXE и хеши производственных исходников: [build-info.json](build-info.json).

- Окончательная сборка `Windows-6.9.0-preview`: `test.ps1 -NoBuild -Suites overload,overload-ui,compound,compound-ui,train60,robot-transmission60 -SkipProceduralKernel`, каталог `test-results-materials/accepted`. 84 проверки общего корпуса, 29 расчётных проверок материалов/нагрузок, отдельные проверки интерфейса и старых цепочек/шарниров. Проверены RU/EN, светлая/тёмная палитра, сохранение значений при переключении оформления, недопустимый NaN до истории/экспорта и восстановление корректного значения, видимость рассчитанного прижима муфты.
- Общая регрессия на промежуточной сборке 6.9.0: полный `test.ps1` с наборами `overload,overload-ui,compound,compound-ui,train60,robot-transmission60,wave56-fast,author-view,controller,self,mechanism,step,placement,preset,micro,print`. После финальных изменений в редакторе повторены перечисленные выше целевые проверки на окончательном EXE. Процедурный CAD: 66 утверждений, 14 запусков; сохранён исходный [отчёт](legacy-procedural-results.json).
- Native STEP с материалами повторно импортирован: 46 связных положительных тел без муфты, 53 с муфтой, отсутствие значимых пересечений при пороге 0,001 мм³. В этих двух проверках исходных пар пересечений также нет. [Результаты](materials-native-results.json). Геометрия производственного генератора после этой проверки не изменялась; последующие исправления касались редактора, канонического сравнения истории и отображения прижима.
- ZIP/STL: 12 печатных деталей с материалами, 14 с муфтой. Проверены размер файла, замкнутость, ориентация рёбер, габарит 256 мм и BOM. [Без муфты](overload-materials.stl.audit.json), [с муфтой](overload-clutch.stl.audit.json).
- Базовые регрессии ядра, STEP-редактирования, сечений/эскиза, gizmo и движения пройдены через `test.ps1`.

Снимки интерфейса: [перегрузка](overload-ui-overload-table.png), [вал и эпюра](overload-ui-shaft-loads.png), [внутренние детали](overload-ui-overload-3d.png), [общий корпус](compound-ui-compound-3d.png).

Не подтверждены прочность PETG, полный диапазон столкновений, контактная выносливость, ресурс, нагрев, ползучесть, осевая фиксация и работа габаритного модуля муфты.
