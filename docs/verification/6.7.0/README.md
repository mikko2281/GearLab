# Проверки 6.7.0

Итоги машинных проверок находятся в файлах *results.txt и *results.json этой папки. GUI-снимки относятся к локальной Windows-сборке. Новые проверки охватывают независимые CAD-тела, актуальность кешей, реальные отверстия, подробные подшипники, совпадение фланцев в 24 позах и запрет экспорта устаревшего тела после редактирования.

Нативная проверка отдельно перестраивает плечо после изменения длины, стенки и длины двигателя, проверяя изменение физического объёма STEP; для длины проверяется перемещение монтажного фланца. Проверка GUI открывает фактические CAD-сетки и изменяет шарнир без повторной триангуляции.

Перечисленные проверки не являются расчётом прочности и подтверждением печатной готовности. [Ограничения](../../reference67/README.md).
