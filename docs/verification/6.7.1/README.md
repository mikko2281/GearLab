# Проверки исправления 6.7.1

`gripper671-results.txt` — фактический локальный интерфейс: сборка, объекты сцены и треугольные сетки сохраняются при закрытии/раскрытии. Счётчики WebGL подтверждают отсутствие clear и повторной передачи сеток. Проверены камера, положение руки, undo/redo, экспорт и совпадение с повторно открытым проектом. `gripper671-core-results.txt` проверяет раскрытия 0, 2, 12, 26 и 40 мм без интерфейса.

`contacts/robot671-contact-results.json` и `contacts/pose-*-results.json` — точные пересечения импортированных CAD-тел в шести позах (градусы J1…J6):

1. 0, −10, 25, 0, 15, 0;
2. 0, 0, 0, 0, 0, 0;
3. 0, 30, −60, 0, 30, 0;
4. 0, 20, −35, 15, −20, 25;
5. 30, −20, 35, −30, 25, 45;
6. −30, 15, −30, 45, −30, −45.

Порог положительного объёма пересечения — 0,05 мм³. Проверяются корпуса, валы, моторные габариты и захват. Крепёжные пары, тела качения подшипников и гибкие кабельные эскизы исключены. Отчёты исходной 6.7 сохранены как `before-pose-*-results.json` для первых трёх поз. Эта проверка не сертифицирует движения между позами и весь диапазон.

`reference67-native-results.json` проверяет реальные изменения STEP-объёма при изменении длины, стенки и длины мотора. Остальные *results.* — регрессионные проверки прежних рабочих разделов. GUI-снимки относятся к локальной сборке; сервер повторяет проверки без интерактивного WebView и отдельно проверяет свой переносной архив.

Проект остаётся предварительной конструкцией. Нужны передача, привод захвата, реальная характеристика мотора, расчёт прочности/ползучести, посадки, крепления и секционирование под P1S. [Ограничения](../../reference67/README.md).
