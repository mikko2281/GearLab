# GearLab 6.9.0 — материалы, нагрузки и перегрузка

Отдельная локальная предварительная версия после 6.8.0, ветка `feature/material-loads`. Публикация и слияние в main не выполнены.

Добавлены назначение/редактирование материалов, личный справочник, масса по объёмам и плотности, экспорт материалов в STEP/BOM, расчёт круглого выходного вала по фактическим опорам, частные оценки предельного момента и отчёты TXT/CSV. Ползунок показывает условную перегрузку; выход останавливается, вход продолжает движение. Необязательная муфта получает отдельный модуль и расчёт заданного трения/прижима. Робот показывает предел редуктора и предупреждает о чрезмерном моменте привода.

Необоснованные пределы остаются «не определено», а не заменяются оценками с выдуманными коэффициентами. Реальная скорость проскальзывания неизвестна; анимация схематична. Муфта пока является геометрическим проектом с габаритным пакетом и пружиной. **ReadyForManufacture=false**.
