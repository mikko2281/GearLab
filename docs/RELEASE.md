# Текущий выпуск: GearLab 6.8.0

Описание: [RELEASE_6.8.0.md](RELEASE_6.8.0.md).
Обновление этого файла в main запускает общий workflow publish.yml.
Выпуск публикуется как предварительный; существующие релизы не заменяются.
Проверка истории учитывает действующий бюджет 64 МиБ для CAD-кэша.
CI сохраняет записанные байты исторических CS/PS1-файлов без преобразования окончаний строк.
Сохранение байтов распространяется также на официальные уведомления закреплённого SDK WebView2.
