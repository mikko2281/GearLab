# Двигатель из STEP пользователя

Проверены локальные файлы `STEPPERONLINE_Nema17_Stepper_Motor.STEP` и `Nema17_Motor_Screw.STEP`. Оба прочитаны Open CASCADE; проверка BRepCheck успешна. SLDPRT не преобразовывался: для измерения использованы предоставленные STEP.

| Измерение в STEP | Значение, мм |
| --- | ---: |
| Квадратный габарит корпуса | 41,9 × 41,9 |
| От монтажной плоскости до задней стенки | 37,5 |
| Шаг четырёх отверстий | 31,3 × 31,3 |
| Центры отверстий относительно оси | ±15,65 |
| Цилиндры отверстий в модели | Ø2,5 |
| Центрирующий бурт | Ø22 × 2 |
| Цилиндрическая часть вала | Ø4,65 |
| Выступ вала от монтажной плоскости | 23,2 |
| Плоскость D-среза от оси | 1,725 |
| Боковой разъём: максимальный вылет от оси | 26,25 |
| Винт из отдельного STEP: стержень / габарит головки | Ø2,9 / Ø5,15 |
| Винт: длина от опорной плоскости головки до конца | 30 |

Координаты исходника: монтажная плоскость Y=0; корпус направлен по +Y, вал по −Y. Программа использует локальную ось Z мотора и переносит монтажные размеры на ось шарнира.

Шаблон **«STEPPERONLINE по вашему STEP»** сохраняет измеренные корпус, шаг креплений, бурт и выступ вала. Отверстия в печатной плите проектируются как проходные под M3 с редактируемым зазором. Резьба исходника не определяется только по цилиндру Ø2,5. Полноразмерный 30-мм винт из отдельного STEP не используется автоматически как монтажный винт мотора: его назначение и допустимую глубину завинчивания нужно подтвердить.

Отличия от условного NEMA17-шаблона (42,3 мм, шаг 31 мм, вал Ø5 мм) сохранены намеренно. Геометрия предоставленной модели может отличаться от реального изделия. До изготовления измерьте свой мотор; модель не подтверждает его каталожный артикул, электрические характеристики или допуски.

Встроенная модель — редактируемый монтажный габарит. Разъём, D-срез, фаски и резьба не воспроизводятся полностью. Оригинальный STEP остаётся отдельным справочным файлом пользователя. Исходные сторонние CAD-файлы и изображения не включены в публичное распространение без установленного разрешения правообладателя. Таблица содержит только измерения.

Момент, рабочие обороты и масса не извлекаются из STEP. Пример сохраняет условные 0,35 Н·м / 400 об/мин / 0,28 кг, которые следует заменить. При применении шаблона по STEP уже введённые момент и масса не изменяются.

Чёрно-оранжевая схема — визуальный ориентир по приложенным изображениям, а не копия их конструкции. Сначала определяются приводы, опоры и траектории, затем редактируются оболочки.

Воспроизводимое измерение: `python tools/inspect_motor.py path/to/motor.STEP path/to/screw.STEP`, требуется cadquery-ocp. Отчёт содержит границы, оси цилиндров и плоскости.
