# GearLab 6.9.1 — анимация и общий корпус ПТК

Исправление локальной предварительной версии 6.9.0. Старые EXE и архивы сохранены. Ветка `codex/fix-common-housing-animation`; публикация в GitHub не выполнялась.

Возвращены анимации Клода из проверенной папки `GearLab-review-claude`: последовательное появление деталей, плавное разнесение и сборка, анимация робота в Three.js. Детали одного подшипника раздвигаются вместе. Для общего корпуса сохраняются группы модулей. Анимации меняют только отображение; экспорт, сечения и перемещение деталей используют итоговые положения.

Исправлена ошибочная проверка `RingOutput` у планетарной ступени. Этот параметр переключает выход у циклоидальной передачи; у планетарной и ПТК неподвижные кольца задаются их собственной геометрией.

Волновая ПТК работает в общем корпусе: сохранены профиль дорожки, генератор, 17 шариков базового примера и связный сепаратор. Для его фланца добавлена круглая камера над дорожкой, для буртика входа — осевое место над опорой. Общий вал сохраняет перемычки сепаратора; D-/шлицевой стык учитывает короткую входную шейку. STEP и STL используют те же параметрические сечения.

В разделе «Ступени» есть пример «ПТК → планетарный в одном корпусе». Для собственной цепочки выберите типы, включите общий корпус и задайте одинаковые выходной/следующий входной диаметры. Оба диаметра теперь видны в инспекторе. Кнопка «Согласовать валы» явно устанавливает следующий вход по предыдущему выходу. Несовместимые диаметры по-прежнему дают ошибку с размерами. Верхние кнопки переносятся на следующую строку и остаются доступны.

Пример ПТК 17:1 → планетарный 4:1: подписанное отношение −68, выход −4,412 об/мин при входных 300. Момент вычисляется по заданному КПД и не означает допустимую нагрузку конструкции.

Проверки и пределы: [отчёт](verification/6.9.1/README.md). **ReadyForManufacture=false**. Проверка дискретных положений CAD не подтверждает непрерывное отсутствие столкновений, ресурс, прочность или готовность к изготовлению.
